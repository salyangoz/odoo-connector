Amazon Seller Global Connector

Connect Odoo to Amazon Seller Global through Yengeç

  1. Install Amazon Seller Global Connector for free.
  2. An Odoo administrator clicks the Amazon Seller Global icon in the home menu.
  3. Yengeç opens with your Odoo connected and takes you to your Amazon Seller Global integration.

Odoo'yu Yengeç ile Amazon Seller Global'a bağlayın

  1. Amazon Seller Global Connector'ı ücretsiz yükleyin.
  2. Bir Odoo yöneticisi ana menüdeki Amazon Seller Global simgesine tıklar.
  3. Yengeç, Odoo'nuz bağlı olarak açılır ve sizi Amazon Seller Global entegrasyonunuza götürür.
