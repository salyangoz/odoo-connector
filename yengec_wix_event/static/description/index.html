Wix Event Connector

Connect Odoo to Wix Event through Yengeç

  1. Install Wix Event Connector for free.
  2. An Odoo administrator clicks the Wix Event icon in the home menu.
  3. Yengeç opens with your Odoo connected and takes you to your Wix Event integration.

Odoo'yu Yengeç ile Wix Event'a bağlayın

  1. Wix Event Connector'ı ücretsiz yükleyin.
  2. Bir Odoo yöneticisi ana menüdeki Wix Event simgesine tıklar.
  3. Yengeç, Odoo'nuz bağlı olarak açılır ve sizi Wix Event entegrasyonunuza götürür.
