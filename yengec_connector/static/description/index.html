Yengeç Connector

Seamlessly connect Odoo to Yengeç in minutes

Install this free module and click Yengeç in the home menu to launch the guided setup wizard on the Yengeç platform. No technical knowledge required.

How it works

  1. Install Yengeç Connector from the Odoo App Store.
  2. Click the Yengeç icon in the Odoo home menu.
  3. You are redirected to the Yengeç setup wizard.
  4. Follow the on-screen steps to configure the integration.
  5. Return to Odoo — the connection is ready.

What you get

  • One-click redirect to Yengeç's guided configuration
  • Automatic transfer of your Odoo instance URL and database ID
  • No manual API key entry required in Odoo
  • Fully free — no subscription needed for this module

About Yengeç

Yengeç is a business management platform that integrates with Odoo to synchronize your data and streamline your workflows. Visit yengec.co to learn more.
